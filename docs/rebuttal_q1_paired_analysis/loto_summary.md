# Leave-one-task-out (LOTO) robustness of the Mean6 pairwise comparisons

Generated by `paired_analysis.py`; source rows are in `loto_mean6.csv`. For each of the 15 pairs at each epoch, the commonsense mean is recomputed six times, each time without one of ARC-e, HellaSwag, PIQA, SIQA, OBQA, CSQA (an unweighted five-task mean). Each variant is paired within seed exactly as in the full analysis. **Supported** is the criterion used throughout this directory: all three per-seed differences have the same sign *and* |mean| > SD. A variant *keeps* a supported comparison if it meets that criterion in the same direction. All values are accuracy points, written as winner minus loser, mean ± SD (seeds > 0).
